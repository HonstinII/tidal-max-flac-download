Local Tidal workstation

Tidal Max FLAC Studio

A local desktop/web UI built around streamrip for personal offline listening: Tidal binding, Max/Hi-Res FLAC downloads, cover embedding, lyrics tagging, output folder controls, and a guided setup flow.

Download for macOS Download for Windows
Step 1

Prepare the environment

Open the app and finish the tool check.
If streamrip, ffmpeg, or metaflac is missing, use the setup screen to install the required tools.

Step 2

Link Tidal

Click the Tidal authorization link and sign in on Tidal.
Return to the app after authorization; it will detect the token and unlock the download workspace.

Step 3

Paste URLs and download

Copy a Tidal album or track URL into the app.
Choose an output folder, keep covers and lyrics enabled, then start the FLAC download.
