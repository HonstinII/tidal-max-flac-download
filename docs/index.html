Local Tidal workstation

Tidal Max FLAC Studio

A local web UI built around streamrip for personal offline listening: Tidal binding, Max/Hi-Res FLAC downloads, cover embedding, lyrics tagging, output folder controls, and a guided setup flow.

This page is not the downloader.

GitHub Pages can only host this static guide. To use the app, run it locally on your Mac, then open http://127.0.0.1:8000.

Open GitHub repository streamrip by nathom

1. Clone and install

git clone https://github.com/HonstinII/tidal-max-flac-download.git
cd tidal-max-flac-download
./scripts/install.sh

2. Start the local app

.venv/bin/python -m uvicorn app.main:app --reload

Then open http://127.0.0.1:8000 in your browser.

3. Bind Tidal and download

Use the setup screen to install missing tools, bind your Tidal account, paste Tidal track or album URLs, choose an output folder, then start the FLAC download.

Core

The core downloading foundation is streamrip, created by nathom. This project builds a local studio workflow around that tool.

Integrated

The app adds guided Tidal binding, one-click missing tool setup, Tidal URL queues, cover embedding, lyrics tagging, and Finder output controls.

Local first

GitHub Pages is only this static project page. The downloader itself runs locally because it needs your local tools, tokens, and files.
