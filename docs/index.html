Tidal Max FLAC Studio

A local desktop/web UI built around streamrip for personal offline listening: Tidal binding, Max/Hi-Res FLAC downloads, cover embedding, lyrics tagging, output folder controls, and a guided setup flow.

Open GitHub repository streamrip by nathom

1. Download release

Open GitHub Releases and download Tidal-Max-FLAC-Studio-macOS.zip or Tidal-Max-FLAC-Studio-Windows.zip.

2. Open the app

Unzip the file and open Tidal Max FLAC Studio. macOS users can move the app to Applications; Windows users can run the executable inside the unzipped folder.

3. Bind Tidal and download

Use the setup screen to install missing tools, bind your Tidal account, paste Tidal track or album URLs, choose an output folder, then start the FLAC download.

Core

The core downloading foundation is streamrip, created by nathom. This project builds a local studio workflow around that tool.

Packaged

GitHub Releases provides downloadable macOS and Windows builds. Developers can still build locally with the package scripts.

Local first

GitHub Pages is only this static project page. The downloader itself runs locally because it needs your local tools, tokens, and files.
