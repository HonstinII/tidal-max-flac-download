Local Tidal workstation

Tidal Max FLAC Studio

A local desktop/web UI built around streamrip for personal offline listening: Tidal binding, Max/Hi-Res FLAC downloads, cover embedding, lyrics tagging, output folder controls, and a guided setup flow.

Download for macOS Download for Windows All releases Open GitHub repository streamrip by nathom

Tidal Max FLAC Studio by HonstinII. Core downloading is powered by streamrip, created by nathom.

Step 1

Prepare the environment

Open the app and finish the tool check. Install missing core tools from the setup screen if the app asks for them.

Step 2

Link Tidal

Click the Tidal authorization link, sign in on Tidal, then return to the app after the token is detected.

Step 3

Paste URLs and download

Paste Tidal album or track URLs, choose the output folder, then start the FLAC download with covers and lyrics enabled.
