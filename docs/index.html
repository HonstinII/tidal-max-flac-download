Tidal Max FLAC Studio

Tidal Max FLAC Studio is a local Tidal download workstation built around the open-source project streamrip. It brings Tidal binding, download settings, cover embedding, lyrics writing, and metadata cleanup into a desktop interface.

Main features

  • macOS and Windows desktop builds.
  • Guided checks for streamrip, ffmpeg, metaflac, and local configuration.
  • Tidal authorization through the official Tidal login page.
  • Automatic preview parsing for Tidal track and album links.
  • Max / High quality selection with FLAC and AAC fallback handling.
  • Cover embedding, lyrics writing, .lrc files, and metadata cleanup.
  • copyright, ISRC, UPC, title, artist, album, year, track, and disc metadata.
  • Download queue, retry, log export, existing-file handling, and open-file-location controls.
Step 1

Download and open the app

Download the macOS or Windows build and open the app.
The first screen checks the local tools needed for downloading and post-processing.

Step 2

Complete the environment check

If a required tool is missing, follow the one-click install flow or use the manual download link shown in the app.
Optional cover tooling can also be installed later when cover embedding is enabled.

Step 3

Bind Tidal

Click the bind button and sign in on Tidal's official authorization page.
The app detects the authorization token after the login is complete.

Step 4

Paste a Tidal link

Paste a Tidal track or album URL into the downloader.
The app parses the link and shows a preview before downloading.

Step 5

Choose settings and download

Choose Max or High, set the output folder, and decide whether to embed covers and lyrics.
After downloading, use the queue to retry failures, export logs, or open the saved file location.
